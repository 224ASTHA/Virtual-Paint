# 🎨 Virtual Paint Using OpenCV

## 📌 Overview
Virtual Paint is a computer vision project built using Python and OpenCV that allows users to paint virtually by moving a colored object in front of a webcam. It detects the object's color using HSV color space, identifies its outline, and tracks its movement to draw on the screen in real time.

## ✨ Features
- Color detection using HSV.
- Object outline and contour detection.
- Real-time object tracking.
- Virtual painting through object movement.

## 🛠️ Technologies Used
- Python
- OpenCV
- NumPy

## 🚀 Installation & Usage

Install the required libraries:

```bash
pip install opencv-python numpy
```

Run the project:

```bash
python VirtualPaint.py
```

Move a colored object in front of your webcam to start painting virtually.
